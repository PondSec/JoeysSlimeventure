# Chapter 1 quest assets — draft only

Everything in this directory is a **non-final placeholder game asset** supplied
with the Chapter 1 Quest Pack. It exists so the implemented interactions can be
reviewed in-game before final art is commissioned or selected.

- Runtime sprites explicitly use nearest-neighbour filtering.
- The in-game quest tracker identifies these visuals as `DRAFT / NICHT FINAL`.
- Keep replacement assets at the same filenames or update
  `chapter_quest_runtime.gd`'s visual mapping in one place.
- VFX sheets are retained for the next art pass; they are 8 horizontal frames
  and must continue to use nearest-neighbour filtering.
